ELL TEACHER DASHBOARD — SETUP INSTRUCTIONS
================================================

WHAT'S IN THIS ZIP (16 files)
------------------------------
- index.html              Complete page shell (click the title to set your teacher name)
- style.css               All dashboard styling
- connect_u1.js .. connect_u8.js  Vista Connect 3, Units 1-8, 21 sessions each, 30/45/60/90-min pacing (pull-out only)
- savvas_u1.js .. savvas_u5.js    Savvas myView, Units 1-5, 6 weeks each, Below/On Level x Push-In(60min)/Pull-Out(30min)
- tracker.js              Student data tracker (WIDA placement, Dolch/Fluency/DOK sessions, charts)
- app.js                  Full dashboard logic

HOW TO INSTALL
---------------
1. Drop ALL 16 files into one folder.
2. For GitHub Pages: upload all files to your repo, push to main.
3. Open index.html in a browser (works locally too, no server needed).

WHAT'S IN THE DASHBOARD
-------------------------
- Vista Connect 3: 8 units x 21 sessions each. Pill tabs switch between 30/45/60/90-min pacing. Numbered step blocks show exactly how to spend each minute. Prev/Next navigation across sessions. Pull-out delivery notes per session.
- Savvas myView: 5 units x 6 weeks x Below/On Level. Push-In (60 min) and Pull-Out (30 min) plans with Day 1 always whole-group.
- Tracker: Add students via WIDA Reading + Speaking scores (auto-placed). Click any student to open their file. Sight Words = Dolch word grid. Fluency = interactive passage word selector. Comprehension = DOK 1-4 checkboxes (2 questions each, 20 pts max). Charts with goal line + peer average.
- Click the dashboard title to set your teacher name (saved to localStorage).

Re-paste the Code tab into the ZIP Builder any time files change to get a fresh zip.
